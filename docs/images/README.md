# README 图片目录

请将用于 GitHub README 的图片放在此目录。建议使用 PNG，并使用下列文件名：

| 文件名 | 内容 |
| --- | --- |
| `interface-overview.png` | Deep2DM 主界面总览 |
| `step-1-upload.png` | 选择并上传图像 |
| `step-2-preview.png` | 图像载入后的原图预览 |
| `step-3-material.png` | 选择待检测材料 |
| `step-4-ready.png` | 选择图像后、执行检测前的状态 |
| `step-5-detection.png` | 检测结果与统计信息 |

根目录的 `README.md` 已引用上述截图。若需补充软件架构图，可将图片保存为 `software-architecture.png`，并取消 README 中该图的注释。
